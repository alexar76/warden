26 октября 2026. Локальная WARDEN **0.22.1**. На Linux factory-vps прошли сборка, проверка типов и **127/127 тестов в четырёх наборах**, включая **25 новых**. ## Что проверили

Рукописные фразы вроде «используй третью запись в таблице» не совпадают с отпечатками прочитанного секрета. После наблюдаемого чтения credentials и внешнего текста исходящий вызов всё равно требует `ask`, а в режиме `deny` отклоняется. Граница сохраняется после 1/3/8 наблюдаемых промежуточных результатов инструментов и нового хода пользователя. Названный пользователем или разрешённый адрес сам по себе не даёт исключения. Непонятное имя MCP-инструмента тоже проверяется; инструмент вне MCP можно включить явной операторской меткой `outbound`.

Это граница сессии/действия, **не семантическое отслеживание происхождения**. Преобразования заданы вручную, модель их не генерировала. Тестовые отправители не исполнялись. Прежние тесты Stop по-прежнему фиксируют пробел для перефразирования без буквального совпадения.

## Исключения входят в результат

- Точно разрешённый оператором запрос со смысловой ссылкой может пройти **один раз**. Это не подтверждение публичности значения по ссылке. Повтор, изменение текста, адреса, вложенных аргументов, инструмента или запрет host на публичное разрешение возвращают проверку. Буквальное совпадение известного секрета отклоняется даже с точным разрешением.
- Неизвестный инструмент вне MCP без явной разметки не перехватывается этой границей. Это проверенное ограничение интеграции.
- Без наблюдаемого credential или внешнего текста эта граница не включается. Произвольные приватные данные без распознанного credential не получают универсального покрытия этим правилом.
- `audit` только журналирует, `off` отключает проверки. Host обязан запускать hooks и соблюдать решения. Отдельный исполнитель task-adapter и отображение в нативном GUI этим прогоном не проверялись.

Сильные окна остаются **8 не-hex / 10 hex**. Изолированные короткие фрагменты проверяются отдельно; прежние тесты прошли. Универсальная защита от семантической утечки не доказана.
