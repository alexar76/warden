# Живой прогон модели через структурированный ответ

[en](flow-guard-structured-model-2026-10-26.md) · [ru](flow-guard-structured-model-2026-10-26.ru.md) · [es](flow-guard-structured-model-2026-10-26.es.md) · [fr](flow-guard-structured-model-2026-10-26.fr.md) · [zh](flow-guard-structured-model-2026-10-26.zh.md)

26 октября 2026. Прежний локальный WARDEN **0.22.0**, без публикации npm. Продолжение [механизма проверки ответа приложением](flow-guard-answer-gate.ru.md) и [эксперимента с четырьмя формулировками](flow-guard-review-factors-2026-10-26.ru.md).

## Как проверяли

160 свежих вызовов `deepseek-flash` на Linux factory-vps: temperature .3, thinking выключен, JSON object mode, максимум 700 выходных токенов. Использована та же замороженная сборка `createAnswerGate`. Проверяются все правила, полное множество допустимых записей и минимум цены. Ответы модели не редактировались для получения разрешения.

Двенадцать сохранённых контекстов содержат исходный диалог с инструментом, внешнюю инструкцию и прежний текст ответа. Новый запрос пользователя требует полностью заменить ответ четырьмя полями по нормализованному каталогу. По восемь повторов дают 96 естественных переходов на новый контракт: четыре исходных контекста содержали ложные объяснения, восемь — корректные. Вместе меняются контракт, каталог и инструкция; это не изолированный тест формата.

Отдельно для четырёх контекстов с прежней ошибкой искусственно задаются неверные начальные списки: правильное множество плюс C (цена 190 > 150) или D (расстояние 2,5 > 1). Восемь повторов каждого типа дают **64 контролируемые начальные ошибки**. Их создал экспериментатор, не модель. Такой список занимает начальную попытку SDK, после которой разрешено максимум два живых исправления. Для естественного перехода начальная попытка тоже живая. Доли этих двух групп не объединяются.

## Результат

| Группа | Результат |
|---|---|
| Естественный переход на новый контракт | **96/96 правильных первых предложений**; поводов для исправления нет |
| Четыре контекста с прежним ложным объяснением | **32/32 правильных первых предложений**, входят в 96 |
| Искусственно заданный C | **32/32 исправлены первым живым ответом** |
| Искусственно заданный D | **32/32 исправлены первым живым ответом** |
| Свежие ответы с C/D в допустимом списке, неверным/дублированным JSON либо лишними полями | **0/160** |
| Финальные кадры приложения | **160 проверенных результатов, 160 уведомлений, непроверенных кандидатов нет** |

Оба заранее зафиксированных прогноза выполнены: >=80/96 правильных первых естественных ответов и >=48/64 исправленных контролируемых случаев. На каждую траекторию понадобился один реальный вызов API. Ошибок API, замены C→D и отброшенных попыток не было.

**Второе исправление и удержание в живом прогоне не понадобились.** Их успешность на живой модели этим запуском не измерена. Прежние детерминированные и stdio-тесты по-прежнему подтверждают только работу соответствующих путей механизма.

На измеряемой структурированной поверхности добавления ложного старого утверждения не наблюдалось. В схеме один список допустимости; полей для свободного объяснения, собственной цены или отдельного исключения нет. Это не доказывает исправление произвольной прозы. Одновременно с форматом изменены нормализованный каталог и инструкция; нет одновременного контроля с прозой и независимого набора. Повторы относятся к двенадцати известным контекстам, поэтому полный счёт не является общей гарантией надёжности или защиты от инъекций.

## Выдача, проверка и стоимость

Уведомление формировало само приложение. В финальных кадрах только проверенные структурированные данные. После сбора результаты заново сверены с исходными фактами отдельным расчётом, без вызова runtime-валидатора. Измерены сохранённые кадры выдачи; отображение в стороннем нативном GUI не проверялось. Истинность внешнего источника, произвольные объяснения, полномочия на платежи/действия и скрытое влияние на выбор среди равных вариантов остаются вне результата.

До API на Linux прошли 9 Node-тестов адаптера, 28 тестов relay/бюджета/сбора и 480 предварительных проверок запросов. У контейнера нет сети и ключа; официальный API доступен только серверному relay. Все запросы и ответы сохранены, 333 выходных хеша проверены до удаления временного каталога. Автоповторов транспорта и повторного исследования не было. Runtime менять не потребовалось.

Все вызовы прошли вне пикового времени. Usage: 211 200 входных токенов, из них 103 936 кешированных; 17 946 выходных. По [опубликованному тарифу](https://api-docs.deepseek.com/quick_start/pricing/) расчёт составляет **$0,027169008**; консервативный пиковый учёт — **$0,054338016**, ниже лимита **$0,15**. Счёт и изменение баланса провайдера отдельно не проверялись. Использован существующий сервер.

Подготовка и разбор выполнены с AI, без слепой независимой проверки человеком. Ничего не опубликовано в GitHub/npm, комментарий не отправлен.
