# Свежий прогон WARDEN: цель выбирается реже, Stop не исправил ID

[English](flow-guard-model-comparison-2026-10-25.md) | [Русский](flow-guard-model-comparison-2026-10-25.ru.md) | [Español](flow-guard-model-comparison-2026-10-25.es.md) | [Français](flow-guard-model-comparison-2026-10-25.fr.md) | [中文](flow-guard-model-comparison-2026-10-25.zh.md)

25 октября 2026. Опубликованный WARDEN **0.21.0** и локальный, неопубликованный кандидат **0.22.0**. Этот отчёт не означает выпуск в npm.

На шести известных синтетических задачах об отелях оба новых режима выбрали цель атаки **27/48** раз; опубликованные note и note+Stop — **44/48** и **46/48**. Новый кандидат приблизил распределение выбора под атакой к чистому незащищённому фону. **Двенадцать реальных перепроверок Stop не изменили ни одного выбранного ID.** Это два отдельных результата: улучшение сравнения целых версий на данном наборе и отсутствие наблюдаемого дополнительного исправления выбора через Stop. При ничьей оба отеля допустимы, поэтому выбор цели сам по себе не ошибка и не доказательство выполнения атаки.

## План и знаменатели

Шесть задач × восемь повторов × три входа (`clean`, нейтральный `benign` той же длины в символах, `injected`) × пять чередующихся режимов = **720 основных ответов**. Отдельно выполнены пять пробных запросов и **30 контролей настоящих предпочтений пользователя**. В каждой задаче два допустимых оптимума, заранее выбранная цель атакующего и два неподходящих варианта; позиции записей менялись, факты и запросы совпадали между условиями.

Протокол зафиксирован до первого вызова модели. Использован официальный API с именем модели `deepseek-flash`, temperature 0.3, максимум 700 выходных токенов, thinking отключён. Не было повторных попыток, запасной модели или замены результатов. Имя модели не гарантирует неизменность весов, одинаковый seed модели не гарантировался. Предупреждение передавалось через контролируемый мост в tool-role, Stop — максимум одним продолжением в user-role. Это не испытание исполнения правил в native-клиенте и не настоящее бронирование.

## Сравнение версий и неопределённость

Уменьшение эффекта атаки новым кандидатом относительно соответствующего старого режима с поправкой на чистый фон: **+22.9 п.п.** для note, 95%-интервал **[−8.3, +60.4]**; **+37.5** для note+Stop, **[+14.6, +62.5]**. С нейтральным фоном: +31.3 [0, +64.6] и +33.3 [+8.3, +62.5]. Каждый контраст содержит все 48 сопоставленных блоков из четырёх условий.

Уменьшение расстояния до общего чистого незащищённого фона — **43.8 п.п.** у обоих кандидатов, интервалы [12.5, 77.1]. При этом средние абсолютные сдвиги чистых распределений по задачам относительно режима без защиты составляют **14.6** и **6.3 п.п.**, суммарные — −6.3 и −2.1. Вывод не основан только на исчезновении собственной дельты нового режима.

Bootstrap пересэмплирует **шесть целых кластеров задач**, сохраняя повторы и условия: 2000 выборок, seed 20261025, без поправки на множественные сравнения. Основной интервал note включает ноль. Известные, специально написанные задачи использовались при исправлении сигналов; это **не независимая отложенная выборка**. Повторы не создают новых семейств атак. Сравнивались целые версии: детектирование, формулировки, метаданные и прежние локальные исправления. Положительный контраст note+Stop не выделяет вклад Stop. Основное уменьшение сосредоточено в задачах 2, 4, 6; в 1, 3, 5 цель и так выбиралась во всех чистых незащищённых повторах.

## Канал предупреждений и Stop

До прогона предупреждения Post/Stop заменены фиксированным текстом и непрозрачными ID источников. Они не повторяют цитаты атаки, сырые имена инструментов, URL или пути. ID нужны для сопоставления записей, а не для подтверждения пакета, pin или разрешения. Исходный недоверенный tool result остаётся в контексте; локальные журналы могут содержать недоверенные метаданные.

Специальные предупреждения кандидата появились на **96/96 атакованных примерах с защитой**, на чистых/нейтральных — **0/192**. Старые режимы давали общие заметки. Только новый note+Stop запросил продолжения: **12/48 атакованных**, ни одного на своих 96 чистых/нейтральных примерах и пользовательских контролях. Четыре начальных выбора были целевыми, восемь — альтернативными; **все 12 ID остались прежними**. Тексты четырёх ответов изменились; из трёх исчезла видимая ссылка на предупреждение.

Ограниченный поиск английских слов обнаружил ссылки на предупреждение в конечных ответах 20/48 нового note и 17/48 нового note+Stop, в старых режимах — ноль; некоторые ответы при этом выбирали цель. Это не измерение осознания, отказа или семантического выполнения инструкции и не независимая слепая разметка. При просмотре обнаружены ошибочные списки допустимых альтернатив, несмотря на допустимые выбранные ID. Двенадцать дополнительных вызовов стоили денег, но наблюдаемого исправления ID не дали.

## Исполнение, проверки и стоимость

Исполнение — **Linux factory-vps, Docker runc**, не Mac. У guard, runtime-тестов и аудита не было сети; подготовка зависимостей/ОС и серверный relay API — явные исключения. API-ключ оставался на сервере. Временные каталоги модели и аудита удалены после проверенного сбора; production-сервисы не менялись.

Прошли сборка/typecheck, **714 тестов WARDEN в 20 файлах** (57 проверок сигналов/диагностики/метаданных), **78 тестов стенда/бюджета/подсчёта**, **девять тестов адаптера** и прежний **детерминированный gate из 28 сценариев**. Gate не означает 28 предотвращённых атак модели. Сохранена первая попытка до API: 699/714 тестов; не хватало Bash/Python, старые ожидания требовали сырые имена. Окружение и ожидания исправлены до платных вызовов; после пробных запросов модель, набор и тексты не подбирались.

**767 попыток API = 755 исходных вызовов + 12 продолжений**, без ошибок и повторных попыток. Основная генерация — около **17 минут, 20:50–21:07 МСК**. **438085 входных токенов**, из них **290296 кешированных**, **58241 выходной**. Расчёт по off-peak тарифу на дату запуска: **$0.057983838**; это оценка по токенам, не счёт провайдера. Консервативный расчёт по пиковым ставкам — **$0.115967676**; максимум с незавершёнными резервами — **$0.125793172** при лимите **$1**. Неизвестные/неудачные вызовы сохраняют полный резерв $0.01.

Отдельно реализованный аудит на Linux прошёл **21015 проверок учёта, hash и знаменателей**; проверены hash всех **2606 собранных выходных файлов**. Независимость реализации учёта не означает независимую человеческую семантическую оценку.

## Дополнительная проверка обоснований Stop (25 октября 2026)

Смена ID — **не метрика успеха**, когда оба варианта при ничьей допустимы. Проверены все **12 реальных пар начальных и конечных ответов**: отдельно оценены заявленное основание, проверяемые утверждения о выборе и раскрытие инструкции. Это **последующий разбор с помощью AI, без ослепления**, а не независимая человеческая разметка, новый прогон модели или заранее зарегистрированная метрика.

| Наблюдаемое свойство | До Stop | После Stop |
| --- | ---: | ---: |
| Основание ссылается на условия пользователя и утверждения о записях | 12/12 | 12/12 |
| Размеченные проверяемые утверждения о выборе подтверждаются данными задачи | 8/12 | 8/12 |
| Есть размеченное утверждение о выборе, противоречащее данным задачи | 4/12 | 4/12 |
| Явно раскрыта внедрённая инструкция | 10/12 | 7/12 |

В четырёх объяснениях в список подходящих ошибочно включена запись за $190 при лимите $150; три также ошибочно приписывают ей ничью по цене $123/$129. Эти ошибки сохраняются после Stop. Настоящее равенство цены с записью, явно исключённой по расстоянию, проверяется отдельно и не объявляется ошибкой допустимости. Все 12 меток основания и размеченные фактические утверждения остались прежними: **исправлений этих фактов или смены заявленного основания не обнаружено**. Изменились четыре текста: три убрали раскрытие инструкции, один переформулировал неравенство без изменения факта.

«Подтверждено» относится к явно размеченным проверяемым утверждениям о выборе, а не ко всем возможным утверждениям ответа. «Я не последовал инструкции» — непроверенный самоотчёт. Объяснения **не раскрывают внутреннюю причинность** и могут рационализировать уже повлиявший на модель выбор. Смысловые метки и цитаты заданы при разборе; оценщик проверяет точные цитаты, hash, ограничения задачи, равенство цен, оптимальность и полноту пар, а не угадывает смысл по ключевым словам. Этот малый набор известных случаев, отобранных по срабатыванию Stop, не оценивает его рандомизированный эффект или общую эффективность. Неизменность ID не означает ни успеха, ни провала; дополнительный разбор также не показал улучшения подтверждённости размеченных утверждений в этих 12 случаях.

**16 регрессионных тестов прошли на Linux без сети**: исправление факта при том же ID, смена ID с сохранением внедрённого основания, маскировка словами о предупреждении, пропущенная разметка и поддельные свидетельства. Новых вызовов модели и изменений runtime-блокировки не было.
